## A hierarchy that stays quiet

Headings use a medium weight. **Bold text** adds emphasis without changing its color. Links such as [Obsidian Help](https://help.obsidian.md) use the same blue as list markers.

### Notes that grow with you

- Start with an observation.
  - Add the context that matters.
  - Link a related idea.
- Keep paragraphs short enough to revisit.

### 为中英文笔记留出空间

一段话不需要太多装饰。用清晰的标题组织材料，用列表记录下一步，用引用保留值得反复阅读的句子。

> Good notes make the next conversation easier.

---

### Keep the source readable

Inline code such as `captureIdea()` has a light, unobtrusive background. Empty lines inside code blocks retain their height.

```python
def capture_idea(text):
    """Make a small space for a useful thought."""

    return {"idea": text, "next_step": "revisit"}
```

> [!tip] Use your own font size
> Lark follows Obsidian's font-size preference. The default rhythm is 16px text with a 26px line height.
